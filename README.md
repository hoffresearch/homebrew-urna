# homebrew-urna

homebrew tap for [urna](https://github.com/hoffresearch/urna).

```sh
brew install hoffresearch/urna/urna
urna setup
```

<img src="urna-brew.svg" alt="brew install hoffresearch/urna/urna: the tap, the trusted formula and the release binary, then urna --version" width="100%">

the formula in `Formula/` is generated by cargo-dist on every tagged release of `hoffresearch/urna`; do not edit it by hand. it installs the binary only: `urna setup` then lays down the offline embedder and a Python env under the data dir, outside anything brew owns, and ends on the doctor checks. `brew upgrade urna` moves to the next release.
